# ContentGuard(учебный проект)

Браузерное расширение для фильтрации токсичного контента и NSFW-изображений на устройстве.

ContentGuard работает полностью в браузере — без серверной обработки, без отправки данных за пределы устройства. Расширение использует локальную ONNX-модель **toxic-bert-russian-onnx** через [`@xenova/transformers`](https://github.com/xenova/transformers.js) для классификации токсичности русскоязычного текста, а также применяет эвристическую фильтрацию для обнаружения взрослого контента на изображениях.

---

## Возможности

- **Обнаружение токсичного текста** — классифицирует русскоязычный текст (комментарии, посты, статьи) на токсичность с помощью локальной BERT-модели.
- **Обнаружение NSFW-изображений** — эвристически определяет и размывает потенциально взрослые изображения на странице.
- **Фильтрация в реальном времени** — сканирует страницу при загрузке и автоматически размывает найденный токсичный контент.
- **Клик для просмотра** — затемнённые элементы можно кликнуть, чтобы убрать размытие.
- **Приватность превыше всего** — вся классификация выполняется локально, без сетевых запросов для вывода модели.
- **Настраиваемые пороги** — регулировка порога токсичности текста через всплывающее окно расширения.
- **Без внешних зависимостей во время выполнения** — использует только локальные статические ONNX-файлы модели.

---

## Как это работает

1. **Контент-скрипт** (`content.js`) инжектируется на каждую страницу (`run_at: document_start`) и ожидает завершения загрузки страницы.
2. Скрипт сканирует DOM на наличие текстовых элементов, соответствующих популярным селекторам комментариев и постов (например, `.comment-text`, `p`, `h1`, абзацы статей).
3. Каждый найденный фрагмент текста (>40 символов) проходит классификацию через ONNX-модель **toxic-bert-russian-onnx**.
4. Текст с очень высокой вероятностью токсичности (score > порог) **размывается**, при этом клик убирает размытие.
5. Изображения, превышающие порог размера (80×80 пикселей), эвристически оцениваются и размываются, если помечены как NSFW.
6. **Фоновый сервис-воркер** (`background.js`) загружает модель один раз и слушает запросы на классификацию через `chrome.runtime.onMessage`.
7. Настройки сохраняются в `chrome.storage.sync` и управляются через интерфейс всплывающего окна.

## Структура проекта

```
contentguard/
├── manifest.json          # Манифест расширения (MV3)
├── background.js          # Фоновый сервис-воркер — загрузка модели и обработка сообщений
├── content.js             # Контент-скрипт — сканирование DOM, классификация, затемнение
├── package.json           # Конфигурация сборки (esbuild + @xenova/transformers)
├── dist/                  # Сборленные файлы (генерируются командой `npm run build`)
│   ├── background.js
│   └── content.js
├── popup/
│   ├── popup.html         # Интерфейс всплывающего окна
│   └── popup.js           # Логика всплывающего окна — сохранение/загрузка настроек
└── models/
    └── toxic-bert-russian-onnx/   # Локальные файлы ONNX-модели
```

## Установка

### Требования

- [Node.js](https://nodejs.org/) (v18+)
- [Модель]([https://nodejs.org/](https://huggingface.co/Lopulex/toxic-bert-russian-onnx-quantized))
- npm

### Сборка

```bash
npm install
npm run build
```

Эта команда упаковывает `background.js` и `content.js` в каталог `dist/` с помощью esbuild.

### Установка в Chrome / Edge

1. Откройте `chrome://extensions/` (или `edge://extensions/`).
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.
4. Иконка расширения появится на панели инструментов — клините по ней, чтобы настроить пороги.

## Настройки

| Параметр             | Описание                                        | Значение по умолчанию |
|----------------------|-------------------------------------------------|-----------------------|
| **Включено**         | Включить/выключить расширение                   | `true`                |
| **Порог текста**     | Минимальный score токсичности (0.50–0.95)       | `0.75`                |
| **Порог изображений**| Минимальный NSFW score (0.0–1.0)                | `0.80`                |

Настройки синхронизируются между браузерами через `chrome.storage.sync`.

## Разрешения манифеста

| Разрешение     | Зачем нужно                                    |
|----------------|-------------------------------------------------|
| `storage`      | Сохранение и загрузка пользовательских настроек |
| `activeTab`    | Доступ к активной вкладке                       |
| `<all_urls>`   | Инъекция контент-скрипта и доступ к модели      |

Политика безопасности контента разрешает `wasm-unsafe-eval` для выполнения ONNX Runtime в WebAssembly.

## Разработка

```bash
# Установка зависимостей
npm install

# Скрипты сборки (упаковка с помощью esbuild)
npm run build          # Сборка контент-скрипта и фонового скрипта
npm run build:content  # Сборка только content.js
npm run build:background  # Сборка только background.js
```

> После любого изменения в исходниках необходимо пересобирать скрипты — расширение загружает файлы из каталога `dist/` (пути указаны в `manifest.json`).

## Модель

**toxic-bert-russian-onnx** — классификатор токсичности на русском языке на основе BERT, конвертированный в формат ONNX. Модель хранится локально в каталоге `models/` и загружается во время выполнения с параметром `local_files_only: true`, что означает отсутствие сетевых запросов для загрузки весов модели.

- Файлы модели доступны контент-скрипту через `web_accessible_resources`.
- Квантизация отключена (`quantized: false`) для максимальной точности классификации.

---

## Ограничения

- Обнаружение текста ориентировано на конкретные CSS-селекторы; на некоторых сайтах может потребоваться добавление новых селекторов.
- Фильтрация изображений использует эвристическую оценку, а не выделенную модель классификации изображений.
- Поддерживается только русскоязычный текст.
